C.P Phone GPS Edge Driver v1.0.5

- PhoneGPS-Logger API: http://NAS_IP:8787
- 현재 위치 조회: /api/phones
- 수동 새로고침: POST /api/refresh
- SmartThings 화면 표시 개수: 1~4
- 설정 변경 시 cp-phone-gps-1 ~ cp-phone-gps-4 프로필로 동적 전환
- Phone 표시: -연제구 연산동 2320, 6m 형식
- ESL 연동 시 최대 2개 표시 예정
- 제작자: 치즈가루

설치:
1. 압축 해제
2. SETUP-AND-INSTALL.cmd 실행
3. 설치 후 SmartThings 앱 완전 종료/재실행
4. 주변 기기 검색
5. 설정에서 NAS IP / 포트 / 표시 개수 / 갱신 주기 설정
